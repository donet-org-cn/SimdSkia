# SimdSkia 0.1.6

0.1.6 优化了图片编解码、CPU 形态学滤镜、Vulkan 纹理上传和 PDF 栅格页写入。十三个 NuGet 包统一为 0.1.6，目标框架为 .NET 10，编解码依赖为 Sdcb.SimdCodecs 2.0.0。

```sh
dotnet add package SimdSkia --version 0.1.6
```

## 更新内容

- GIF 首帧可直接合成到目标缓冲，连续读帧复用当前画布。ICO 和 WebP 解码减少中间分配。
- TIFF 编码分条转换和压缩。可直接解码的分条 TIFF 写入目标像素缓冲，其他输入走通用路径。新 TIFF 的分条布局与 0.1.5 有差异，Pillow 独立解码核对了像素。
- JPEG 编码跨线程复用像素缓冲，共享池最多保留 32 MiB 空闲像素缓冲。PDF 栅格页写入减少整页中间复制。
- CPU 膨胀和腐蚀按行列复用滑动窗口极值计算。Vulkan 将像素写入映射的上传缓冲，减少纹理更新时的整图复制。
