# SimdSkia 0.1.6 与 NuGet 0.1.5 性能对比

2026-11-18 · Windows x64 · i7-12700（AVX2）· RTX 3060 · .NET 10.0.14

基线使用从 NuGet.org 下载的 0.1.5 正式包。独立的 `PackageReference` 项目完成包还原、绘制与解码，实际加载的九个 SimdSkia DLL 的 SHA-256 与下载包一致。待发布的 0.1.6 使用同一工作负载和外部依赖，编解码器为 Sdcb.SimdCodecs 2.0.0，Avalonia 为 12.1.5。[NuGet 0.1.5](https://www.nuget.org/packages/SimdSkia/0.1.5) · [包与程序集哈希](evidence/nuget-0.1.6-performance-2026-11-18/provenance.json) · [独立项目实际加载的程序集](evidence/nuget-0.1.6-performance-2026-11-18/package-smoke.json)

## 固定工作量

混合负载包含 2,304 帧 CPU 绘制、384 次静图解码、192 帧动画解码、48 次编码和 48 次滤镜。纯 CPU 绘制使用同样的 2,304 帧。各负载交替运行五对独立进程，固定到同一个逻辑核心。表内是两个版本各自的中位数。

| 负载 | 总耗时（秒） | 进程 CPU 用时（秒） | 累计托管分配 | 峰值工作集（MiB） | 结束时私有内存（MiB） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 绘制与图片混合 | 6.00 → 4.77 | 5.80 → 4.64 | 735.46 MiB → 339.97 MiB | 215.6 → 214.1 | 136.8 → 165.3 |
| 纯 CPU 绘制 | 2.80 → 2.78 | 2.78 → 2.72 | 848 B → 848 B | 46.0 → 45.9 | 20.6 → 20.6 |

混合负载用时减少 20.6%，CPU 用时减少 19.9%，累计托管分配减少 53.8%。五对进程的 CPU 用时均下降，降幅在 10.8% 至 26.0% 之间。计时期间第 2 代 GC 次数的中位数从 18 次降至 4 次。

混合负载结束时，工作集由 159.4 MiB 增至 187.6 MiB，私有内存增加 20.8%。主动执行完整 GC 后，工作集从 159.4 MiB 变为 175.1 MiB，私有内存从 136.8 MiB 变为 152.3 MiB，存活托管对象从 36.53 MiB 变为 36.07 MiB。累计托管分配衡量任务执行期间申请的字节总量，峰值工作集衡量从进程启动到测量结束期间的最大物理内存驻留量。[逐轮数据](evidence/nuget-0.1.6-performance-2026-11-18/overall/runs.json) · [摘要](evidence/nuget-0.1.6-performance-2026-11-18/overall/summary.json)
