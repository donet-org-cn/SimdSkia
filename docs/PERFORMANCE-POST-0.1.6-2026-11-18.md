# 0.1.6 发布后的位图、GC 和 CPU 复测

2026-11-18，Windows x64，Intel Core i7-12700，NVIDIA GeForce RTX 3060，.NET 10.0.14。基线取自 NuGet.org 的 0.1.6 正式包，候选为本地源码。两者使用相同的基准可执行文件、图像、字体和依赖。在同一组内交替运行独立进程，逐轮核对输出哈希。[本轮数据](evidence/post-0.1.6-2026-11-18.json)

## 位图流的分配来源

以四个 960×720 的 BGRA 像素缓冲轮换绘制时，正式版的分配跟踪记录到 `Direct2DCanvas.CachedBitmap` 为已变化的内容创建整帧比较快照。每个数组 2,764,800 字节。按每秒 16 帧绘制时，仅此一项就相当于约 42.19 MiB/s。原生窗口的 160 帧采样记录到 17 次由大对象分配触发的 Gen 2 回收。

普通可变像素缓冲现可复用比较快照。对至少 128 KiB、由 Avalonia 写锁更新的位图，Direct2D 使用写入版本识别变化，省去了每张位图的整帧快照。同一批绘制包含多次修改时，已排队的绘制保留各自的纹理内容。[Direct2D 图像缓存](../src/SimdSkia.Gpu.Direct2D/Direct2DCanvas.cs) · [位图写锁回归](../tests/GpuPreferred/Program.cs)

下面用 Avalonia 的写锁更新四张轮换位图。三个进程各完成 120 次更新，每帧等待 GPU 完成并读回。存活大对象堆在计时结束后的完整回收后取样。

| 指标 | NuGet 0.1.6 | 复用比较快照 | 使用位图版本 |
| --- | ---: | ---: | ---: |
| 每帧托管分配 | 2,765,322 B | 367 B | 367 B |
| 120 帧内 Gen 2 回收 | 13 | 0 | 0 |
| 存活大对象堆 | 23.73 MiB | 23.73 MiB | 13.18 MiB |
| 进程峰值工作集 | 149.09 MiB | 102.52 MiB | 94.62 MiB |
| 每帧耗时 | 2.365 ms | 2.091 ms | 1.447 ms |
| 每帧进程 CPU 用时 | 2.995 ms | 2.344 ms | 1.953 ms |

## 其他路径

每项测试三对，表内为各版本的中位数。OpenGL 使用 WGL 硬件上下文和 960×720 输入，等待 GPU 完成。PNG 使用 640×480 带透明度的图像。指定滤镜的 64 个 PNG 样本在两个版本中的编码字节完全一致。

| 操作 | 耗时，0.1.6 → 候选 | 每次托管分配，0.1.6 → 候选 |
| --- | ---: | ---: |
| 更新 OpenGL 紧凑 RGBA 预乘纹理 | 1.692 → 1.109 ms | 2,765,231 → 116 B |
| 更新 OpenGL 带行填充的 BGRA 非预乘纹理 | 9.468 → 1.356 ms | 2,770,988 → 224 B |
| 指定 PNG Sub 滤镜编码 | 101.089 → 62.246 ms | 14,490,461 → 9,371,046 B |
| PNG 在 None 和 Sub 之间逐行选择 | 108.899 → 70.229 ms | 14,496,483 → 9,376,162 B |
| Avalonia 从可访问底层数组的 MemoryStream 读取 PNG | 1.935 → 1.637 ms | 1,234,007 → 4,038 B |
| 租用并初始化不透明像素缓冲 | 0.864 → 0.071 ms | 106 → 106 B |

Direct2D、OpenGL 与 Metal 共享像素格式转换代码。Windows 本机验证了 WGL、ANGLE、Direct2D 和 Vulkan 的像素输出，Metal 完成编译，真机测量仍待 macOS 验证。[各帧像素顺序回归](../tests/Shared/MutableBitmapUploadValidation.cs)

## 固定工作量

在同一个逻辑核心上，混合任务每轮完成 2,304 帧 CPU 绘制、384 次静图解码、192 帧动画解码、48 次编码和 48 次滤镜。三对中位数的总耗时从 4.947 秒变为 4.861 秒，进程 CPU 从 4.578 秒变为 4.734 秒，托管分配从 339.974 MiB 变为 339.972 MiB，两版均发生 4 次 Gen 2 回收。

另做七对长测，每个进程纯 CPU 绘制 4,608 帧。总耗时中位数从 5.286 秒变为 5.513 秒，CPU 从 5.031 秒变为 5.109 秒，两版都只分配 848 B，均未触发 GC。候选的总耗时在七对中有五对更长，配对差异范围为 −19.6% 至 +16.6%。这组负载没有显示整体 CPU 加速。

将同一绘制拆成每段 144 帧，在同核两个预热进程间交替执行。三对进程各跑 16 段，共 48 个配对。每段的进程 CPU 中位数均为 156.25 ms，各对 CPU 周期变化的中位数为 −2.0%。三对进程分别为 +3.3%、−3.9% 和 −2.3%，收益方向随进程组变化。
