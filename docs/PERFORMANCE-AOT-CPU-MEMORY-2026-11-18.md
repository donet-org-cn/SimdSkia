竖向渐变每行只需采样一次。斜向渐变仍需逐像素计算，五轮耗时中位数从 547 升到 566 μs，按轮配对有三轮上升、两轮下降。

字体族匹配直接扫描元数据，字符回退复用最近一次样式排序并保持同等候选的注册顺序。可直接访问的 MemoryStream 在原切片上查重，单独注册的新 TTF 使用自有快照。字形位置直接读取已校验的 loca 表，省去额外的整型索引。回归覆盖流的起始偏移、当前位置、调用者修改原数组以及中文回退。[字体匹配与流](../src/SimdSkia.Avalonia/Fonts.cs) · [TrueType 字形索引](../src/SimdSkia.Text/TrueTypeFont.cs)

命中测试直接遍历轮廓，弱引用供相邻指针事件复用。重新编辑几何对象会使缓存失效，GC 可收回轮廓。变换共享相同的填充和描边路径，单种画笔的描边绕过字典。竖向渐变按行采样，独立的旋转或斜切着色器矩阵继续逐像素计算。合成时连续完全不透明的像素可直接写入。[几何命中与描边](../src/SimdSkia.Avalonia/Geometry.cs) · [路径变换](../src/SimdSkia.Core/PathGeometry.cs) · [渐变](../src/SimdSkia.Cpu/LinearGradientKernel.cs) · [图像合成](../src/SimdSkia.Cpu/ImageCompositor.cs)

| 场景 | 耗时 s | 进程 CPU s | 总分配 MiB | 峰值 WS MiB | 存活堆 MiB |
| --- | ---: | ---: | ---: | ---: | ---: |
| 纯 CPU 绘制 4,608 帧 | 4.834 → 4.723 | 4.688 → 4.672 | 0.0008 → 0.0008 | 45.93 → 45.93 | 5.84 → 5.84 |
| 绘制与编解码混合 2,304 帧 | 4.296 → 4.241 | 4.250 → 4.219 | 339.9688 → 339.9752 | 218.70 → 219.21 | 35.96 → 35.96 |

长测在原生编译结束后重新执行。另让两个预热进程轮流在同一核心渲染 144 帧，三组各 16 对。48 对的进程 CPU 周期配对变化中位数为 -1.34%，其中 39 对减少。混合负载每轮包含 384 次静图解码、192 帧动画、48 次编码和 48 次滤镜。

混合场景 CPU 中位数变化为 -0.74%，总分配相差 +6.6 KiB。热点的节省在整条管线里只占较小比例。

RTX 3060 在 640×360 Vulkan 小程序中实际执行了矩形批处理。初始化后完整 GC 的托管存活量为 1,153,360 → 979,352 B，减少 169.9 KiB。每次创建管线只打开所需 SPIR-V 资源，在对齐的映射流上直接创建模块，其他流临时读入对齐缓冲。首次提交累计分配为 253,976 → 253,624 B，预热后工作集为 58.82 → 58.82 MiB。这项收益体现在长期被引用的托管对象上。[Vulkan 模块创建](../src/SimdSkia.Gpu/VulkanShaderCode.cs) · [Khronos Vulkan 主机内存生命周期](https://docs.vulkan.org/spec/latest/chapters/fundamentals.html)

## 正确性与复测

70 个桌面 NativeAOT 进程均完成真实窗口呈现、位图检查和固定姿势截图，同场景的 RGBA 哈希一致。独立 CPU、Direct2D 和 Vulkan 前后共 30 个原生进程，按后端的像素哈希一致。控件通过 14,015 项断言，开启和关闭硬件 SIMD 各通过 474,472 项精确字节检查，编解码通过 204,420 项断言。另有 116 张控件 PNG、91 份编码器输出、9 份像素传输结果与既有基准逐字节一致。RTX 3060 通过 599 项 Vulkan 检查。

扩展工作负载包含 32 项静图、动画、滤镜、像素缩放、路径和 PDF 操作，各运行两对进程并比较校验值。测试的静图格式覆盖 PNG、JPEG、WebP、GIF、BMP、ICO、TIFF、QOI、Netpbm、JPEG 2000 和 JBIG2。编解码器依赖沿用同一版本，报告中的明显改进集中在字体和绘制。

复测时使用相同的 RID、SDK、ISA、字体和编译偏好。下列命令以当前工作区的源码为输入。

```powershell
dotnet publish examples/AvaloniaAot/SimdSkia/AvaloniaAot.SimdSkia.csproj -c Release -r win-x64 --artifacts-path artifacts/build-ui-speed -p:OptimizationPreference=Speed -o artifacts/native-ui-speed
dotnet publish examples/AvaloniaAot/SimdSkia/AvaloniaAot.SimdSkia.csproj -c Release -r win-x64 --artifacts-path artifacts/build-ui-size -p:OptimizationPreference=Size -o artifacts/native-ui-size
./artifacts/native-ui-speed/AvaloniaAot.SimdSkia.exe --hidden --scene controls --scale 1 --mode throughput --warmup 0.75 --seconds 2 --output artifacts/native-ui-metrics
dotnet run -c Release --project tests/PlatformFonts -- --footprint baseline/fonts/ZCOOLXiaoWei-Regular.ttf
dotnet run -c Release --project tests/PlatformFonts -- --installed-fallback
dotnet publish benchmarks/NativeFootprint -c Release -r win-x64 -p:FootprintBackend=Vulkan -o artifacts/native-vulkan
./artifacts/native-vulkan/NativeFootprint.exe
```

结论适用于这台 Win64 机器。桌面 AOT 采用可移植指令集，实测 128 位向量。CoreCLR 在同机启用了 AVX2。NativeAOT 可执行文件大小依赖应用能触及的 API。工作集受系统文件映射、GC 和图形驱动影响，长时间视频播放和 Android、iOS 的原生包大小需要在对应设备测量。
