# Independent PDF fixtures

`external.pdf` and `alpha.pdf` are generated by `tools/generate-pdf-fixtures.py`
with ReportLab 5.1.0 and Pillow 13.0.0. They contain paths, RGB images, image
soft masks, page rotation, compressed streams and an embedded CJK TrueType subset.
They are not generated by SimdSkia. The embedded ZCOOL XiaoWei font is SIL OFL
1.1; see the adjacent `ZCOOLXiaoWei-OFL.txt`. Geometry and test content are MIT.

Ordinary C# tests use the checked-in PDFs without Python or a native PDF library.
Independent visual validation uses development-only PyMuPDF and pypdf; neither
is linked, loaded or redistributed by the engine or optional PDF reader.
