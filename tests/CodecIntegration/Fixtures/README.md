# Independent codec fixtures

Generated by `tools/generate-codec-integration-fixtures.py` from first-party 13×9
pixel arrays; no downloaded photographs or third-party source code are included.
Pillow 12.2.0 uses native libwebp/OpenJPEG/TIFF only as isolated test oracles.
`oracle.json` freezes their decoded pixels and `SHA256.json` identifies the files.
Regenerate only for an intentional fixture change, never to disguise a decoder failure.

`blank.jb2` is a normative T.88 sequential standalone file (page information,
end-of-page, EOF), not an oracle for symbol dictionaries/arithmetic region coding.
`gamma.png` is generated directly with PNG chunks and standard zlib; its gAMA=1.0
mid-grey value must transform to sRGB 188. This catches the difference between
code-value projection and colour conversion.

The GIF fixtures linked from CompatibilityExpansion retain their own provenance.
